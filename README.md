## 🎓 Educational Focus / Pädagogisches Konzept

### 🇬🇧 English
This repository serves as a structured blueprint for programming instructors and IT teachers. It is designed to introduce absolute beginners to software development without overwhelming them with corporate design patterns:

* **Contiguous Procedural Paradigm:** Strictly no Object-Oriented Programming (OOP). The codebase relies purely on loops, conditions, structures, and arrays.
* **Granular Sub-Routines:** The software is systematically broken down into small, highly understandable procedures. Each module (e.g., collision checking, movement, tail trailing) can be extracted as an isolated programming exercise.
* **Dual-Language Bridge:** To mirror real-world industry standards, all variables, constants, and procedure names are written strictly in **English**. However, the deep line-by-line documentation inside the source code is written in **German** to lower the barrier for native students.

* **State-of-the-Art Industrial Design:** Although procedural, the code implements production-grade architecture. Students learn clean separation of concerns, structured data layouts, and deterministic game loops—foundational paradigms used heavily in modern high-performance game engines and safety-critical industrial software.
* **Gamification & Playful Learning:** Developing a retro classic leverages high-engagement learning. Students see immediate visual and auditory feedback for every line of logic they change, turning abstract programming concepts (like array boundaries and coordinate systems) into a tangible, fun experience.

### 🇩🇪 Deutsch
Dieses Projekt wurde gezielt als Lehrmaterial für den Programmierunterricht an Schulen und in Ausbildungskursen entwickelt. Unter Anleitung eines Ausbilders eignet sich der Code ideal für den ersten Einstieg in die Softwareentwicklung:

* **Rein prozedurale Programmierung:** Es wird bewusst auf Objektorientierung (OOP) verzichtet, da diese von PureBasic auch nicht nativ unterstützt wird. Der Fokus liegt ganz auf den algorithmischen Grundlagen.
* **Verständliche Sub-Routinen:** Der Code ist extrem sauber modularisiert. Jede Teilaufgabe (z. B. Kollisionsprüfung, Bewegung, Punktestand) bildet eine eigene Sub-Routine, die im Unterricht als separate Programmierübung herausgegriffen werden kann.
* **Zweisprachige Brücke:** Alle Variablen- und Funktionsnamen sind durchgehend in **Englisch** gehalten. Dies schult das technische Verständnis und erlaubt erfahrenen Codern, die Logik sofort zu erfassen. Die umfangreiche Dokumentation direkt im Code ist jedoch komplett auf **Deutsch** verfasst.

* **Industrielle Best Practices:** Obwohl rein prozedural, vermittelt der Code professionelle Design-Prinzipien der Softwareindustrie. Schüler lernen die saubere Trennung von Aufgabenbereichen (Separation of Concerns), strukturierte Datenhaltung und deterministische Spielschleifen – Grundlagen, die in modernen High-Performance-Engines unverzichtbar sind.
* **Spielerisches Lernen (Gamification):** Das Entwickeln eines Spieleklassikers sorgt für maximale Motivation im Unterricht. Schüler erhalten für jede geänderte Zeile Code sofort visuelles und akustisches Feedback. Das verwandelt abstrakte Theorie (wie Array-Grenzen und Koordinatensysteme) in ein praktisches, greifbares Erfolgserlebnis.
